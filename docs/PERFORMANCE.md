# 性能测量

运行 `node tools/benchmark.mjs`。它调用独立的 MoonBit JS benchmark 包，不把 Node 启动或 JSON 解析混入核心展开耗时。

四个场景分别为标量路径、含中文的查询和列表、200 个表达式的长模板、100 个中文列表项。每个场景比较“每次解析再展开”和“解析一次再反复展开”，执行三次预热、七次交替顺序测量，保留每个原始样本、迭代数、输出校验和、工具链、Node、CPU 与平台。

两种模式每批都包含一次相同的变量构造/准备成本；复用模式包含首次解析。用返回的输出长度校验和避免丢弃结果，确保两种模式相同。结果只说明当前机器和输入下的观察，没有任意速度门槛，也不声称优于其他语言库。

原始数据：reports/benchmark.json。长模板与大集合的正确性另由 api_test.mbt 验证，不能用性能结果替代语义测试。
