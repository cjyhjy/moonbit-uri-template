# 性能测量与范围

2026-10-20 在同一机器、固定工具链、JS release 目标上测量三个项目，本轮 JSJ222 更新至 ee7d3be（源码 0.2.0）。全部八组结果公开；本次优化后，本项目在八组的观测中位耗时均最低。这不是所有场景、平台或内存性能全面领先的证据。

## 当前三库基准

三次预热、七轮轮换项目执行顺序。单位为每个样本的毫秒；每行三者使用相同迭代数。环境、源码摘要、全部原始样本与样本最大值见 `reports/peer-benchmark.json`。七个样本的最大值不冒充 p95。

此前优化去除了每个百分号编码字节的重复字符表构造、保留字符检查的临时字符串，以及解析字面量时重复转换字符数组的路径；资源检查与展开语义保留。项目检查另改为编译后复用，但该 Node 工作流收益不包含在此核心基准中。

## 方法与限制

运行 `npm run compare:peers` 后执行 `npm run benchmark:peers`。同一个生成的 benchmark 包引用三家核心，检查源码固定快照及当前核心副本；不包含 CLI、JSON 或网络成本。各样本包含一次绑定准备和初始解析；每次解析模式在循环里再次解析，复用模式复用初始对象。每个样本都检查输出长度校验和，超预算案例确认失败次数。

三者使用有界公开接口，但输入预算语义并不完全相同：本项目和 JSJ222 会检查绑定输入，Magic486 没有同等独立输入限额。大值失败场景使用 10,000 个 emoji 和 32 字节输出预算，其优势只针对该具体输入，不能外推成所有数据下的相同比例。

新增运行时类型契约与增量会话不在这八组核心展开负载中，不能由这些数字比较它们的成本。上一轮旧同类快照的完整结果保留在 `reports/history/before-runtime-contract-20261020/peer-benchmark.json`，不同轮次不用于隔离某个改动的收益。

下节另记录同一台 macOS 主机的四后端进程峰值 RSS；没有执行分配次数或跨操作系统/硬件测量，也没有统计显著性检验。小幅耗时差异可能落在运行抖动内。不根据本次结果写“所有场景最快”或“内存占用最低”。

## 复杂负载、四后端与进程峰值内存

运行 `npm run benchmark:resources`。每个 release 可执行文件只引用一家库，JS 直接启动 Node，wasm/wasm-gc 启动固定 moonrun，Native 直接启动可执行文件；不在计量中运行编译器。每库每场景有 5 个新进程样本，轮换项目执行顺序；每个进程先做 3 次各 50 轮预热。内部单调时钟只计业务循环，另记包含启动、准备和预热的进程墙钟时间。环境、版本、源码及可执行文件摘要、完整原始样本见 `reports/peer-resources.json`。

全部为 MoonBit 核心接口，不含 Node SDK 宿主层、HTTP、CLI、JSON 或页面渲染。三库保留各自公开有界接口的检查，输入预算语义和表示不同。Magic486 没有对应的公开契约、会话、目录审计及批量入口，记为“不适用”。

## 快照存储优化的前后观测

扩展负载优化前完整报告见 `reports/history/before-snapshot-optimization-20261020/peer-resources.json`，对应核心 b331272；中间阶段也在同目录保留。更早的四场景优化前报告（核心 7ffcefa）仍在 `reports/history/before-resource-optimization-20261020/peer-resources.json`，不把它没有执行的新场景补写成历史结果。

| 保留 1001 快照 | 本项目优化前 MiB | 本项目当前 MiB | JSJ222 当前 MiB |
| --- | --- | --- | --- |
| js | 97.55 | 68.39 | 87.83 |
| wasm | 28.98 | 18.42 | 29.95 |
| wasm-gc | 46.02 | 25.45 | 49.38 |
| native | 16.72 | 5.45 | 15.78 |

核心绑定改为共享名字索引和未变的 32 槽块，每次只复制涉及的块；活动索引避免扫描未绑定变量。URI/长度数组仍按快照复制，旧快照仍会占用内存，不能解读为历史数量无限或内存恒定。目录编译时保存排序和静态统计；批量复用已校验的输入码点计数；策略审计不再为统计反复创建完整引用报告。新增回归包含旧快照再次更新、集合输入被调用方修改、失败原子性、删除后重新插入、静态统计及 Unicode 批量预算。

前后是不同轮次，不把全部差值归因于代码。保留 1001 个短值快照仅证明该固定负载；没有证明长时间服务的泄漏情况、所有保留历史模式、其他操作系统/硬件或 Node SDK 宿主实现的收益。尚待覆盖更大目录、长字符串频繁替换、不同保留窗口及应用端完整读取开销。

## 历史自比较

`reports/benchmark.json` 是 0.1.x 的历史“解析复用与重复解析”测量，不代表本轮候选版性能。`node tools/benchmark.mjs` 可重跑该自比较，但不得与本次三库结果混合排名。
