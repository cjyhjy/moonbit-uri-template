# 持续优化与验收范围

目标保持为：覆盖同类有价值的能力，在真实接入、排错、资源控制和升级维护上形成可验证的优势。性能测试领先不能代替接口完整性、易用性或实际采用证明。

## 当前工作

2026-10-20 本轮补齐的实现：

- 变量画像及全部引用：操作符、每次前缀/展开修饰、表达式索引、源码位置，保留统计摘要无法表达的细节。
- 详细契约差异：增加/删除变量、标量限制变化、重复引用、RFC 等级、保留字符/fragment、字面量和表达式布局；旧摘要 API 保持兼容。
- 目录静态策略审计及跨模板请求检查：集中报告多个请求的独立问题；报告、输入和请求数有界，预算超限明确失败。
- Node SDK 分析和比较；还比较必填集合、无用绑定策略以及运行时预算，避免只比较模板文字。
- CLI analyze / compare；变化返回 1、解析失败返回 2，可用在升级检查中。
- 多个必填变量的验证改为索引查找，保持原错误优先级，避免逐项扫描完整引用和遗漏数组。
- 类型化 Node 目录入口：按名称展开、整批计量/生成、跨模板请求预检、策略审计及目录升级比较；模板名、变量名、必填项有类型提示，报告和批量结果有总预算。
- 静态策略的变量白名单建立索引，避免每个引用都扫描完整白名单；新增 JSON 桥接四后端回归和已安装 Node 包消费者验证。
- GitHub 客户端直接使用公共 Node 目录 SDK 生成实际网络请求，文件预检阶段只计量；SDK 对完整请求元数据另计总输入预算。
- 离线升级审查命令：比较目录、类型、总预算和请求变化；候选请求与旧请求分别在新定义下复验，检查目标地址，区分无变化/需审查/阻断/无效输入；六种升级演练单独记录。
- 浏览器工作台支持变量画像、逐次引用跳转、当前/候选模板及独立约束比较，用同一份绑定分别验证两个版本；页面明确提醒单份绑定通过不是兼容性证明。
- 真浏览器验收覆盖桌面和 390 像素窄屏、中文/emoji 与 JSON 定位、预算边界、取消计算、受控延迟触发超时后重试，以及编辑后旧结果/复制失效。页面图片和界面源码摘要独立保存。

验收依据是 `analysis_test.mbt`、SDK/CLI 测试、固定同类共享探针、独立安装消费者及四后端报告。报告只证明所覆盖的行为；以当前源码摘要匹配的验证结果为准。

- 公共运行时类型契约：MoonBit 与 Node SDK 直接声明 scalar/list/assoc，编译规则有预算、形状/必填/来源检查共享核心；目录批量和真实客户端也执行类型约束，类型变化进入升级报告。
- 同类快照更新至 JSJ222 ee7d3be（源码 0.2.0），实测新增类型契约和增量会话；旧快照证据归档，不继续把选择性必填描述为新版缺失。

- 增量链接会话已补齐核心与 Node 入口：不可变更新、依赖重算、原子补丁、整体输入/输出及依赖预算、端点契约；200 次状态变化逐次对比完整重算。作者 GitHub 客户端新增真实参数切换路径，独立记录首次三个请求与仅刷新两条链接的过程。

## 持续推进的范围

1. **性能与资源证据**：保持既有全部场景，增加大量变量/契约审计的场景；另测内存和不同目标，不能以八组 JS 时间结果推断所有平台与 RSS。
2. **可安装交付与采用**：持续验证源码包、Node 包及远端 CI。正式注册表发行和外部开发者接入反馈需分别取得实际记录；作者下游不是第三方采用。

目前不能将整个目标标为完成。不能宣称未来用户会自发选择，也不能把不同许可证、缺失省略策略或稀疏 JSON 语义偏好简单排成高低。
