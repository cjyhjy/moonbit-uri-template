# AI 辅助与项目理解

开发使用 Codex 辅助架构设计、MoonBit 编码、夹具转换、测试分析、CLI、CI 和文档。所有结果以实际编译、测试和运行输出验证；AI 生成不代替参赛者的责任。上游测试独立于实现，没有使用被测函数生成预期 URI。

参赛者应能解释并复现：

1. parser 如何得到隐藏的模板结构，以及为什么解析后可重复使用。
2. 操作符策略如何决定前缀、分隔符、命名输出和编码方式。
3. 普通展开为何编码 `/` 和 `%`，保留字符展开为何允许部分原样输出。
4. 缺失变量、空字符串、空列表之间的差异。
5. prefix 对 Unicode 码点和百分号序列的边界处理。
6. CLI 仅承担进程边界，核心、JSON 适配均由 MoonBit 编写。
7. 270 个上游测试如何固定版本、转换、执行并形成逐文件报告。
8. 单引号兼容扩展的具体原因与标准边界。

演示准备：运行 `npm run demo`；在 `examples/main.mbt` 中将 id 从 42 改成其他字符串并复现；用错误模板展示 code 和位置；查看 `reports/verification.json` 解释测试结果。不要声称尚未发生的报名、公开发布或远程 CI 已完成。
